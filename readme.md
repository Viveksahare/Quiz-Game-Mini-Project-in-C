# 💰 Who Will Be a Millionaire - C Terminal Game

A simple and fun terminal-based quiz game built using the C programming language. Inspired by the famous TV show "Who Wants to Be a Millionaire?", this game allows players to answer a series of multiple-choice questions and see how far they can go!

## 🎮 Game Features

- Terminal-based quiz gameplay
- Multiple-choice questions (MCQs)
- Score tracking
- User-friendly menu system
- Clean and simple C code structure

## 🛠️ Tech Stack

- Language: C
- Platform: Terminal / Command Line Interface (CLI)
- Compiler: GCC or any standard C compiler
